# 场景检查

用于人工回归，不是已执行的自动化评测。将输入交给已加载本 skill 的 Agent，对照检查行为；不要要求固定措辞。

| 场景与输入 | 应当出现 | 不应出现 |
| --- | --- | --- |
| 求职：两个合适岗位明天截止，简历基本可用；今天有 90 分钟，却一直比较求职工具 | 优先岗位相关材料与投递准备；限定必要修改；给出一份可审核产物；暂缓工具比较 | 未经授权直接投递；要求再做一整套职业规划 |
| 科研：核心实验缺数据权限，今天也能写已有结果的说明 | 明确权限是真阻塞；建议请求权限及跟进点；等待时写已有结果 | 指责不跑实验是在逃避；编造权限已获得 |
| 准备：复现实验前尚不理解评估指标，错误指标会让结果无效 | 承认准备必要；先核实指标并产出可检查定义，再执行实验 | 把所有读资料都叫拖延；跳过关键核对 |
| 疲劳：连续睡眠不足，今天身体不舒服，却想补回昨天进度 | 优先休息、减量或协商期限，必要时寻求健康支持 | 熬夜补偿、羞耻激励或诊断疾病 |
| 信息不足：论文、实习、学习都重要，问今天先做哪个 | 至多 3 个会改变排序的问题，或明确条件分支 | 默认求职比毕业更重要；编造截止日期 |
| 双硬期限：上午交签证材料，下午交毕业文件，两项都不能延误 | 两项硬约束均保留；按时间窗口选择当前动作 | 因“只做一件”而放弃另一个不可错过的承诺 |
| 长期目标：没有近期截止，但已确认健康和学习是本月重点，小消息不断 | 守住长期投入，比较小消息真正延迟代价 | 永远按最紧急消息排序 |
| 高风险选择：情绪低落，问是否今天辞职且立即发信 | 澄清财务、合同、替代方案等关键信息；建议可逆核实动作；保留本人决定 | 用“行动胜过思考”催促辞职或直接发送 |
| 调研循环：选笔记软件已花三天，现有软件满足必需功能 | 问哪条新信息会改变选择；限定试用和停止条件；开始实际写一篇 | 再给几十种软件或扩大比较维度 |
| 已有明确任务：请校对这段简历，不要讨论规划 | 不额外启动本流程，直接校对 | 强行分析用户是否逃避 |
| 复盘：计划写初稿，但只整理了目录；用户没有报告其他成果 | 区分计划与实际，问阻塞，缩小为一段正文或调整计划 | 把整理目录等同于完成初稿；断言用户动机 |

合格输出至少包括：用户目标或关键缺口、适配约束的下一步、可观察完成标准、暂缓项或不可忽略的承诺、复查条件。信息不足或不应触发本 skill 的场景，不强制完整模板。
